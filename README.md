# Planet-X Aerospace Services Pvt. Ltd. — Website

A responsive, six-page static website built with HTML, CSS and vanilla JavaScript. It is designed to be opened and edited in Visual Studio Code.

## Pages included

1. `index.html` — Home
2. `about.html` — About Planet-X
3. `programs.html` — Aviation programmes and role areas
4. `careers.html` — Careers at Planet-X
5. `partners.html` — Airwings Aviation Academy and aviation industry ecosystem
6. `contact.html` — Contact details and enquiry form

## Run in Visual Studio Code

1. Extract `planet_x_aerospace_website.zip`.
2. Open the extracted `planet_x_aerospace_website` folder in VS Code.
3. Install the **Live Server** extension (optional but recommended).
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser.

## Customisation

- Change page content directly in the relevant `.html` file.
- Change colours, layout and typography in `css/style.css`.
- Change navigation and contact form behaviour in `js/main.js`.
- Replace the images in `assets/` if updated brand artwork is supplied.
